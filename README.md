# صالون الجمال - نظام حجز المواعيد

تطبيق ويب متجاوب لحجز مواعيد صالون التجميل باللغة العربية مع تكامل واتساب.

## المميزات الرئيسية

- 🏠 **الصفحة الرئيسية**: واجهة أنيقة تعرض خدمات الصالون وساعات العمل
- 📅 **صفحة الحجز**: نموذج شامل لحجز المواعيد مع جميع التفاصيل المطلوبة
- 💬 **تكامل واتساب**: إرسال تلقائي لرسائل التأكيد عبر واتساب
- 👩‍💼 **صفحة الإدارة**: لوحة تحكم لمتابعة وإدارة جميع الحجوزات
- 📱 **تصميم متجاوب**: يعمل بشكل مثالي على الهواتف والأجهزة اللوحية
- 🎨 **تصميم أنيق**: ألوان ناعمة بالوردي والذهبي مع دعم كامل للعربية

## التقنيات المستخدمة

- **React 18** - مكتبة واجهة المستخدم
- **Vite** - أداة البناء السريعة
- **TailwindCSS** - إطار عمل CSS للتصميم
- **React Router** - التنقل بين الصفحات
- **LocalStorage** - حفظ بيانات الحجوزات محلياً

## التثبيت والتشغيل

### المتطلبات الأساسية
- Node.js (الإصدار 16 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd beauty-salon-booking
```

2. **تثبيت التبعيات**
```bash
npm install
```

3. **تشغيل المشروع في وضع التطوير**
```bash
npm run dev
```

4. **فتح المتصفح**
افتح المتصفح وانتقل إلى `http://localhost:5173`

### بناء المشروع للإنتاج

```bash
npm run build
```

الملفات المُبنية ستكون في مجلد `dist/`

## كيفية الاستخدام

### للعملاء
1. زيارة الصفحة الرئيسية لعرض الخدمات
2. النقر على "احجزي موعدك الآن"
3. ملء نموذج الحجز بجميع التفاصيل المطلوبة
4. إرسال الطلب - سيتم فتح واتساب تلقائياً لإرسال رسالة التأكيد

### للإدارة
1. الانتقال إلى صفحة الإدارة
2. إدخال كلمة المرور الافتراضية: `admin123`
3. عرض وإدارة جميع الحجوزات
4. تغيير حالة الحجوزات (مؤكد، مكتمل، ملغي)
5. حذف الحجوزات عند الحاجة

## التخصيص

### تغيير رقم واتساب
في ملف `src/pages/Booking.jsx`، غيّر الرقم في السطر:
```javascript
const whatsappUrl = `https://api.whatsapp.com/send?phone=966501234567&text=${whatsappMessage}`
```

### تغيير كلمة مرور الإدارة
في ملف `src/pages/Admin.jsx`، غيّر المتغير:
```javascript
const ADMIN_PASSWORD = 'admin123'
```

### تخصيص الألوان
في ملف `tailwind.config.js`، يمكنك تعديل ألوان المظهر:
```javascript
colors: {
  'beauty-pink': '#F8BBD9',
  'beauty-rose': '#F48FB1',
  'beauty-gold': '#FFD700',
  // إضافة المزيد من الألوان
}
```
